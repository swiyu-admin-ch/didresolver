# Security Policy

## Supported Versions


| Version                     | Supported |
|-----------------------------|-----------|
| Latest tagged release 2.10.x | ✅       |


DID:TDWs is deprecated and should no longer be used. 

## Reporting a Vulnerability

Incoming security reports will be taken seriously and checked on a regular basis.
If you think you have found a security vulnerability, please report it with the "Report a vulnerability"-form in the "Security" tab.

The project team will then acknowledge, analyze and respond to your report accordingly.
Please do not publicly disclose any vulnerabilities until they have been analyzed and a fix is available.

Thank you for helping us to make our project more secure.

## Bug Bounty

The bug bounty program is limited to the following branches and the newest tagged release on that branch. The relevant
branches are:

- [release/2.10.x](https://github.com/swiyu-admin-ch/didresolver/tree/release/2.10.x)

Vulnerabilities affecting any other branches, older tags, forks and code are out of scope unless explicitly announced as included.
