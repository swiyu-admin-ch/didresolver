# [Criterion.rs](https://bheisler.github.io/criterion.rs/book/getting_started.html) Benchmark Reports

All the reports stored in this directory were generated by running [`cargo bench`](https://doc.rust-lang.org/cargo/commands/cargo-bench.html) on an Apple M3 MacBook Pro featuring total 12 (6 performance and 6 efficiency) cores and 36 GB memory (`sysctl -a machdep.cpu`):

Start browsing the reports [here](https://raw.githack.com/swiyu-admin-ch/didresolver/main/criterion/report/index.html) (or [here](https://htmlpreview.github.io/?https://raw.githubusercontent.com/swiyu-admin-ch/didresolver/main/criterion/report/index.html)).
